# LumiPluginThemePack

📖 English | [中文版](README_zh.md)

Lumi's Kernel adapter for the shared [LumiThemePack](https://github.com/lumi-softworks/LumiThemePack) package. The remote package owns the 19-theme catalog, registration helper, and theme browser/preview UI. This package keeps Lumi's required-plugin metadata, settings entry, localized command menu, and lifecycle cleanup.

Build this package with `swift build`.
